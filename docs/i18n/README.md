# Translations

Localized copies of the project documentation. The **English** documents are
the source of truth ([root README](../../README.md), [docs/](../)); these
translations are best-effort and may lag behind.

## Available locales

### Русский (ru) - [`ru/`](ru/)
- [README](ru/README.md)
- [API contract](ru/api.md)

## Adding a locale

Create `docs/i18n/<locale>/`, copy the English documents you want to translate,
and add the locale to the list above. Keep file names identical to their
English counterparts so links stay predictable.
